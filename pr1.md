# ПРАКТИЧЕСКАЯ РАБОТА
**Тема:** Создание таблиц и базы данных
**Дисциплина:** ОП.06 «Основы проектирования баз данных» / МДК 04.01

### 1. Цель работы
Получить практические навыки:
• создания базы данных;
• создания таблиц различными способами;
• определения типов данных;
• задания ограничений целостности;
• использования первичных и внешних ключей;
• установки автоинкремента;
• создания связей между таблицами;
• настройки каскадного обновления и удаления;
• создания схемы данных;
• заполнения таблиц;
• написания и сохранения SQL-скриптов.

### 2. Постановка задачи
Необходимо создать базу данных информационной системы «Библиотека».

База данных должна хранить информацию:
• о категориях книг (отделах);
• о читателях;
• об авторах;
• о книгах;
• о фактах выдачи книг (выдачах).

Необходимо организовать связи между таблицами и обеспечить целостность данных.

### 3. Структура базы данных
В базе данных необходимо создать следующие таблицы:

**Таблица «Категории»**
| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| category_id | INT | Код категории |
| category_name | VARCHAR(20) | Название категории |
| section | VARCHAR(100) | Секция / Жанр |
| foundation_year | YEAR | Год основания фонда |

**Таблица «Читатели»**
| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| reader_id | INT | Код читателя |
| last_name | VARCHAR(50) | Фамилия |
| first_name | VARCHAR(50) | Имя |
| middle_name | VARCHAR(50) | Отчество |
| birth_date | DATE | Дата рождения |
| category_id | INT | Код категории |

**Таблица «Авторы»**
| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| author_id | INT | Код автора |
| last_name | VARCHAR(50) | Фамилия |
| first_name | VARCHAR(50) | Имя |
| section | VARCHAR(100) | Секция / Направление |

**Таблица «Книги»**
| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| book_id | INT | Код книги |
| book_name | VARCHAR(100) | Название книги |
| pages | INT | Количество страниц |

**Таблица «Выдачи»**
| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| issue_id | INT | Код выдачи |
| reader_id | INT | Код читателя |
| book_id | INT | Код книги |
| issue_date | DATE | Дата выдачи |
| return_status | VARCHAR(30) | Статус возврата |
