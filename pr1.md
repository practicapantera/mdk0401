# ПРАКТИЧЕСКАЯ РАБОТА
**Тема:** Создание таблиц и базы данных
**Дисциплина:** ОП.06 «Основы проектирования баз данных» / МДК 04.01

### 1. Цель работы
Получить практические навыки:
• создания базы данных;
• создания таблиц различными способами;
• определения типов данных;
• задания ограничений целостности;
• использования первичных и внешних ключей;
• установки автоинкремента;
• создания связей между таблицами;
• настройки каскадного обновления и удаления;
• создания схемы данных;
• заполнения таблиц;
• написания и сохранения SQL-скриптов.

### 2. Постановка задачи
Необходимо создать базу данных информационной системы «Библиотека».

База данных должна хранить информацию:
• о категориях книг (аналог учебных групп);
• о читателях (аналог студентов);
• об авторах (аналог преподавателей);
• о книгах (аналог дисциплин);
• о фактах выдачи книг (аналог учебных занятий).

Необходимо организовать связи между таблицами и обеспечить целостность данных.
